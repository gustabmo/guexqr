# guexqr protocol

## 1. QR code (student page → manager app)

Generated by `web/` (`showQR()`), scanned by `managerapp/`.

    guexqr:<group>/<nonce1>/<browser>/<page>/<qrTimestamp>/<nonce2>

Real example:

    guexqr:coursinformatique/JXH0WJTJSA/3TKGPDT3/BtnOnClick/2026-10-20T11:54:05.923Z/22306263

Fields are separated by `/` and read by position:

| # | Field         | Example                     | Notes                                         |
|---|---------------|-----------------------------|-----------------------------------------------|
| 0 | prefix        | `guexqr:coursinformatique`  | `guexqr:` + group (course); fixed so far      |
| 1 | nonce1        | `JXH0WJTJSA`                | 10 random chars A–Z0–9                        |
| 2 | browser       | `3TKGPDT3`                  | random ID stored in a browser cookie          |
| 3 | page          | `BtnOnClick`                | value of the page URL parameter `code`        |
| 4 | qrTimestamp   | `2026-10-20T11:54:05.923Z`  | `Date.toISOString()`, UTC                     |
| 5 | nonce2        | `22306263`                  | 8 random digits                               |

The nonces only make the unblock code unpredictable and the QR
look different on each reload; they are not stored.

### Unblock code

    unblockCode = CRC32(full QR text) mod 100000

Shown by the manager app, typed by the student on the page.

## 2. Log entry (manager app → backend)

HTTP POST to the Apps Script web app URL (kept out of the repo),
`Content-Type: application/json`:

    {
      "group":       "coursinformatique",   // QR field 0 without "guexqr:"
      "student":     "Léa",                 // chosen in the app
      "page":        "BtnOnClick",          // QR field 3
      "browser":     "3TKGPDT3",            // QR field 2
      "qrTimestamp": "2026-10-20T11:54:05.923Z"  // QR field 4
    }

`group` is optional for the backend (defaults to `"A"`); the app always sends it.

Response: HTTP 302 → follow `Location` with a GET → JSON
`{"ok": true}` or `{"ok": false, "error": "..."}`.

Appended to the `Log` tab as:
`logged | group | student | page | browser | qrTimestamp`
